# ft_transcendence: gestão de frota para locadoras

## Description
Sistema web para locadoras que alugam carros para motoristas de aplicativo.
O motorista conversa pelo WhatsApp com um bot que lê fotos do hodômetro e
comprovantes de Pix; a locadora acompanha tudo num painel único: conversas,
pagamentos, quilometragem, revisões e documentos.

O projeto segue Spec Driven Development: a especificação vem antes do código
e fica versionada em `specs/`.
